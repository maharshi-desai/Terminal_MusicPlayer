# CLI Music Player 🎵

A simple terminal-based music player built using **Node.js** for the ISD CLI Music Player Refinement Challenge.

## Features

- ⬆️⬇️ Navigate songs using arrow keys.
- ▶️ Play the selected song with **Enter**.
- ⏸️ Pause and ▶️ resume playback.
- 📊 View song duration and live progress bar.
- ❌ Cleanly switch songs and quit the player.

## Run

```bash
node index.js
```
